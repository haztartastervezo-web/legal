プライバシーポリシー

本通知は Clusters/Four Clues、Number Puzzle、Cryptogram、Magnet Grid、Word Album、Heti Menü/Meal Planner に適用されます。アプリを利用するだけで、任意のデータ処理に同意したことにはなりません。

パズルアプリは進行状況と設定を端末内に保存し、実装されている場合は Cloud Firestore バックアップのために疑似化された Firebase Authentication ID を作成します。Firebase Analytics と Google AdMob/UMP を使用する場合があります。Clusters、Number Puzzle、Cryptogram、Word Album は iOS で ATT を求める場合がありますが、Magnet Grid は現在求めません。Number Puzzle は言語需要の分析のため、端末言語、選択したアプリ言語、プラットフォームも記録し、Firestore に1日最大1回の言語統計イベントを送信します。Meal Planner は機能利用時に、レシピ、メニュー、買い物／パントリー／日記、Firebase同期、Google/Appleログイン、Drive機能、Analytics、Remote Config、Cloud Messaging、ユーザーが選択したファイル／画像を処理する場合があります。

Firebase UID やインストール／インスタンスIDは、必ずしも匿名データではなく、疑似化された技術識別子です。サービス提供者はIP、端末／アプリ情報、許可された広告IDも処理する場合があります。

ゲーム、設定、要求されたバックアップ／同期、サポートに必要な処理はサービス提供のために行われます。セキュリティは正当な利益に基づく場合があります。不要なAnalytics、端末への保存／アクセス、パーソナライズ広告は、法律またはプラットフォーム規則が求める場合に同意に基づきます。AdMob/UMP は同意シグナルと適格性に応じて、パーソナライズ、非パーソナライズ、制限付き、技術的な広告モードを使用できます。パーソナライズを拒否しても、すべての技術処理が停止するとは限りません。ATT は別の許可で、拒否された場合 IDFA をアプリ／サイト横断トラッキングに使用できません。広告同意は自動的にAnalytics全般への同意にはなりません。

複数のアプリはクラウドバックアップのため Firebase ゲスト／匿名アカウントを自動作成します。氏名、メール、パスワードは不要ですが、オンラインの疑似UIDが作られます。アンインストールは通常ローカルデータを削除しますが、クラウドアカウント、Firestore、Analytics、広告または提供者側のデータを必ず削除するわけではありません。削除は、利用可能なアプリ内削除機能、または件名「Data deletion」のメールで開始できます。保存期間は目的、実際の設定、バックアップ／セキュリティ、法的義務に従い、未確認の固定期間は記載しません。

アプリに応じ、Google Firebase/Auth/Firestore/Analytics、AdMob/UMP、Sign-In/Drive/Play Games、Appleサービスが利用されます。国際移転には適用可能な法的保護措置を使用します。GDPR/UK GDPR が適用される場合、アクセス、訂正、削除、制限、異議、データポータビリティ、同意撤回等の権利があります。ハンガリー当局：NAIH naih.hu。アプリは一般向けで、特定処理への同意年齢未満の子どもには保護者の関与が必要な場合があります。

同意の管理

該当する場合、設定 → プライバシー／法的情報 → 広告／プライバシー設定から Google UMP を再表示できます。iOS のトラッキング許可は 設定 → プライバシーとセキュリティ → トラッキング でも変更できます。UMP と ATT は別の管理項目です。任意同意の拒否で主要機能は停止しませんが、広告モードは変わる場合があります。Analytics の保存は別途評価されます。

利用規約

Enila Studio アプリをダウンロードまたは使用することで本規約に同意します。プライバシー同意は別です。一般向けパズル／計画アプリであり、データ同意年齢のみを理由に一律16歳以上の利用制限は設けません。アプリ、デザイン、コンテンツは保護され、合法的な私的利用のための個人的・非独占的・譲渡不可ライセンスが付与されます。サービス妨害、セキュリティ回避、違法利用は禁止されますが、強行法上の権利を制限しません。ネットワーク／クラウド／広告サービスは利用できない場合があります。法律の許す範囲でアプリは「現状有姿」で提供されますが、強行的な消費者権利や排除できない責任は維持されます。居住国の強行的保護を害さない範囲でハンガリー法およびEU法が適用されます。連絡先：haztartastervezo@gmail.com
