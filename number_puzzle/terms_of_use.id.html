Kebijakan Privasi

Berlaku untuk Clusters/Four Clues, Number Puzzle, Cryptogram, Magnet Grid, Word Album, dan Heti Menü/Meal Planner. Menggunakan aplikasi tidak dengan sendirinya berarti menyetujui pemrosesan opsional.

Aplikasi puzzle menyimpan progres dan pengaturan secara lokal dan, bila diterapkan, membuat ID Firebase Authentication pseudonim untuk cadangan Cloud Firestore. Aplikasi dapat memakai Firebase Analytics dan Google AdMob/UMP. Clusters, Number Puzzle, Cryptogram, dan Word Album dapat meminta ATT di iOS; Magnet Grid saat ini tidak. Number Puzzle juga mencatat bahasa perangkat, bahasa aplikasi, dan platform untuk analisis kebutuhan bahasa, termasuk paling banyak satu peristiwa statistik Firestore per hari. Meal Planner dapat memproses resep, menu, belanja/pantry/jurnal, sinkronisasi Firebase, login Google/Apple, fitur Drive, Analytics, Remote Config, Cloud Messaging, serta file/gambar yang dipilih pengguna ketika fitur memerlukannya.

UID Firebase dan ID instalasi/instance adalah pengenal teknis pseudonim, bukan selalu data anonim. Penyedia dapat memproses IP, informasi perangkat/app, dan ID iklan yang diizinkan.

Pemrosesan yang diperlukan untuk game, pengaturan, backup/sinkronisasi yang diminta, dan dukungan digunakan untuk menyediakan layanan. Keamanan dapat berdasar kepentingan sah. Analytics yang tidak wajib, penyimpanan/akses perangkat, dan iklan yang dipersonalisasi menggunakan persetujuan bila hukum/platform mewajibkan. AdMob/UMP dapat menggunakan iklan personal, nonpersonal, terbatas, atau teknis sesuai sinyal persetujuan dan kelayakan. Menolak personalisasi tidak berarti semua pemrosesan teknis berhenti. ATT terpisah; jika ditolak, IDFA tidak dapat digunakan untuk tracking lintas app/situs. Persetujuan iklan bukan otomatis persetujuan umum untuk Analytics.

Beberapa aplikasi otomatis membuat akun Firebase tamu/anonim untuk backup cloud. Tidak memerlukan nama, email, atau kata sandi, tetapi membuat UID online pseudonim. Menghapus aplikasi biasanya menghapus data lokal, tetapi tidak selalu akun cloud, Firestore, Analytics, data iklan, atau data penyedia. Penghapusan dapat dimulai melalui opsi dalam aplikasi bila tersedia atau lewat email dengan subjek “Data deletion”. Retensi mengikuti tujuan, konfigurasi nyata, backup/keamanan, dan kewajiban hukum; kami tidak mencantumkan periode tetap yang tidak terverifikasi.

Tergantung aplikasi, layanan Google Firebase/Auth/Firestore/Analytics, AdMob/UMP, Sign-In/Drive/Play Games dan layanan Apple dapat digunakan. Transfer internasional memakai mekanisme hukum yang berlaku. Jika GDPR/UK GDPR berlaku, hak akses, koreksi, penghapusan, pembatasan, keberatan, portabilitas, dan penarikan persetujuan dapat berlaku. Otoritas Hungaria: NAIH, naih.hu. Aplikasi ditujukan untuk khalayak umum; anak di bawah usia persetujuan untuk pemrosesan tertentu mungkin memerlukan keterlibatan orang tua.

Kelola Persetujuan

Bila berlaku, buka Pengaturan → Privasi/Hukum → opsi iklan/privasi untuk membuka kembali Google UMP. Di iOS, Tracking juga dapat diubah di Pengaturan → Privasi & Keamanan → Pelacakan. UMP dan ATT adalah kontrol terpisah. Menolak persetujuan opsional tidak memblokir fungsi inti; mode iklan dapat berbeda. Penyimpanan Analytics dinilai terpisah.

Ketentuan Penggunaan

Dengan mengunduh atau menggunakan aplikasi Enila Studio, Anda menerima Ketentuan ini; persetujuan privasi terpisah. Aplikasi adalah puzzle/perencanaan untuk khalayak umum tanpa batas penggunaan 16+ secara umum hanya karena usia persetujuan data. Aplikasi, desain, dan konten dilindungi; Anda memperoleh lisensi pribadi, noneksklusif, tidak dapat dialihkan untuk penggunaan pribadi yang sah. Jangan mengganggu layanan, melewati keamanan, atau menggunakan aplikasi secara melawan hukum; hak wajib menurut hukum tetap berlaku. Layanan jaringan/cloud/iklan dapat tidak tersedia. Sejauh diizinkan hukum, aplikasi disediakan “sebagaimana adanya”; hak konsumen wajib dan tanggung jawab yang tidak dapat dikesampingkan tetap berlaku.
