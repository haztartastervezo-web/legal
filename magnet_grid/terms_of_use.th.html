นโยบายความเป็นส่วนตัว

ใช้กับ Clusters/Four Clues, Number Puzzle, Cryptogram, Magnet Grid, Word Album และ Heti Menü/Meal Planner การใช้แอปเพียงอย่างเดียวไม่ถือเป็นความยินยอมต่อการประมวลผลที่เป็นตัวเลือก

แอปเกมเก็บความคืบหน้าและการตั้งค่าไว้ในอุปกรณ์ และหากมีฟังก์ชันดังกล่าวจะสร้าง Firebase Authentication ID แบบนามแฝงสำหรับสำรองข้อมูลใน Cloud Firestore อาจใช้ Firebase Analytics และ Google AdMob/UMP ได้ Clusters, Number Puzzle, Cryptogram และ Word Album อาจขอ ATT บน iOS ส่วน Magnet Grid ยังไม่ขอในปัจจุบัน Number Puzzle ยังบันทึกภาษาของอุปกรณ์ ภาษาที่เลือกในแอป และแพลตฟอร์มเพื่อวิเคราะห์ความต้องการด้านภาษา รวมถึงเหตุการณ์สถิติ Firestore ไม่เกินวันละหนึ่งครั้ง Meal Planner อาจประมวลผลสูตรอาหาร เมนู การซื้อของ/คลังอาหาร/บันทึก การซิงค์ Firebase การเข้าสู่ระบบ Google/Apple ฟังก์ชัน Drive, Analytics, Remote Config, Cloud Messaging และไฟล์/รูปภาพที่ผู้ใช้เลือกเมื่อจำเป็นต่อฟังก์ชัน

Firebase UID และ ID การติดตั้ง/instance เป็น ตัวระบุทางเทคนิคแบบนามแฝง ไม่จำเป็นต้องเป็นข้อมูลนิรนาม ผู้ให้บริการอาจประมวลผล IP ข้อมูลอุปกรณ์/app และตัวระบุโฆษณาที่อนุญาต

การประมวลผลที่จำเป็นมีไว้เพื่อให้บริการที่ร้องขอ ความปลอดภัยอาจอาศัยประโยชน์โดยชอบด้วยกฎหมาย Analytics ที่ไม่จำเป็น การจัดเก็บ/เข้าถึงอุปกรณ์ และโฆษณาแบบปรับให้เหมาะกับบุคคลใช้ความยินยอมเมื่อกฎหมายหรือแพลตฟอร์มกำหนด AdMob/UMP อาจใช้โฆษณาแบบปรับให้เหมาะกับบุคคล ไม่ปรับให้เหมาะกับบุคคล แบบจำกัด หรือแบบเทคนิคตามสัญญาณความยินยอมและสิทธิ์ การปฏิเสธการปรับให้เหมาะกับบุคคลไม่ได้หมายความว่าการประมวลผลทางเทคนิคทั้งหมดหยุดลง ATT เป็นสิทธิ์แยกต่างหาก และหากปฏิเสธจะใช้ IDFA เพื่อติดตามข้ามแอป/เว็บไซต์ไม่ได้ ความยินยอมด้านโฆษณาไม่ใช่ความยินยอมทั่วไปต่อ Analytics โดยอัตโนมัติ

หลายแอปสร้างบัญชี Firebase แบบ guest/anonymous โดยอัตโนมัติเพื่อสำรองข้อมูลบนคลาวด์ ไม่ต้องใช้ชื่อ อีเมล หรือรหัสผ่าน แต่จะสร้าง UID ออนไลน์แบบนามแฝง การถอนการติดตั้งมักลบข้อมูลในเครื่อง แต่ ไม่จำเป็นต้องลบ บัญชีคลาวด์ Firestore, Analytics ข้อมูลโฆษณาหรือข้อมูลของผู้ให้บริการ การลบเริ่มได้จากตัวเลือกในแอปหากมี หรืออีเมลหัวข้อ “Data deletion” ระยะเวลาการเก็บขึ้นอยู่กับวัตถุประสงค์ การตั้งค่าจริง การสำรอง/ความปลอดภัย และกฎหมาย โดยไม่ระบุระยะเวลาคงที่ที่ไม่ได้ตรวจสอบ

ตามแต่ละแอปอาจใช้ Google Firebase/Auth/Firestore/Analytics, AdMob/UMP, Sign-In/Drive/Play Games และบริการ Apple การโอนข้อมูลระหว่างประเทศใช้กลไกทางกฎหมายที่ใช้บังคับ หาก GDPR/UK GDPR ใช้บังคับ อาจมีสิทธิ์เข้าถึง แก้ไข ลบ จำกัด คัดค้าน โอนย้าย และถอนความยินยอม หน่วยงานฮังการี: NAIH, naih.hu. แอปมีไว้สำหรับผู้ใช้ทั่วไป เด็กที่อายุต่ำกว่าเกณฑ์ยินยอมสำหรับการประมวลผลบางอย่างอาจต้องมีผู้ปกครองร่วมดำเนินการ

การจัดการความยินยอม

เมื่อใช้บังคับ ให้เปิด การตั้งค่า → ความเป็นส่วนตัว/กฎหมาย → ตัวเลือกโฆษณา/ความเป็นส่วนตัว เพื่อเปิด Google UMP อีกครั้ง บน iOS เปลี่ยน Tracking ได้ที่ การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → การติดตาม UMP และ ATT เป็นการควบคุมคนละส่วน การปฏิเสธความยินยอมที่เป็นตัวเลือกไม่ปิดฟังก์ชันหลัก รูปแบบโฆษณาอาจแตกต่างกัน และการจัดเก็บ Analytics ต้องพิจารณาแยกต่างหาก

ข้อกำหนดการใช้งาน

เมื่อดาวน์โหลดหรือใช้แอป Enila Studio คุณยอมรับข้อกำหนดนี้ โดยความยินยอมด้านความเป็นส่วนตัวแยกต่างหาก แอปเป็นเกมปริศนา/การวางแผนสำหรับผู้ใช้ทั่วไป และไม่มีข้อจำกัด 16+ แบบเหมารวมเพียงเพราะอายุการให้ความยินยอมข้อมูล แอป ดีไซน์ และเนื้อหาได้รับการคุ้มครอง คุณได้รับสิทธิ์ส่วนบุคคล แบบไม่ผูกขาด และโอนไม่ได้เพื่อการใช้ส่วนตัวที่ชอบด้วยกฎหมาย ห้ามรบกวนบริการ หลีกเลี่ยงระบบความปลอดภัย หรือใช้โดยผิดกฎหมาย โดยไม่จำกัดสิทธิตามกฎหมายที่บังคับใช้ บริการเครือข่าย/คลาวด์/โฆษณาอาจไม่พร้อมใช้งาน เท่าที่กฎหมายอนุญาต แอปให้บริการ “ตามสภาพ” แต่สิทธิผู้บริโภคที่บังคับใช้และความรับผิดที่ไม่อาจยกเว้นยังคงอยู่ ใช้กฎหมายฮังการีและสหภาพยุโรปโดยไม่กระทบการคุ้มครองบังคับของประเทศที่พำนัก ติดต่อ: haztartastervezo@gmail.com
