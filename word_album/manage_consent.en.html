Manage Consent

App name: Word Album
Package name: com.enila.wordalbum
Last updated: September 4, 2026

This document explains what consent the app requests and how you can change it at any time. This page is a supplement to the native consent interfaces (Google UMP form, iOS App Tracking Transparency dialog) — it does not replace them.

1. What consent we request

  • Personalized advertising (EEA/UK/Switzerland): via the Google User Messaging Platform (UMP) consent form, we ask whether you allow advertising-ID-based, personalized ads. Without this consent, the app can only request non-personalized ads.
  • Tracking (App Tracking Transparency, iOS only): via the system's native ATT dialog, we ask permission before using your device's advertising identifier (IDFA) for tracking across other companies' apps/websites for more personalized advertising.

The app does not request consent for account registration or sign-in — the Firebase identifier used for cloud backup is created automatically and anonymously, without separate approval, because no personally identifiable data is attached to it.

2. How to change your consent

  • In the app: Settings → "Manage Consent" (this item only appears where Google requires re-access to ad-consent settings for your region — typically EEA/UK users). Here you can change whether personalized ads are allowed at any time.
  • iOS tracking: device Settings → Privacy & Security → Tracking, where you can allow or block tracking per app.

3. What happens if you decline consent

The app works fully even if you decline consent. If you don't allow personalized ads or tracking, the app shows non-personalized ads instead — this does not affect gameplay, saved progress, or any other feature.

4. Special rights for EEA/UK users

Under Google's EU User Consent Policy, users in the EEA, UK, and Switzerland must give prior consent for advertising-related use of personal data. The app implements this via Google's certified UMP Consent Management Platform, in line with the IAB Transparency and Consent Framework (TCF). You can withdraw your consent at any time as described above.
