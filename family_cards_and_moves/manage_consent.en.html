This page describes the choices you have in the App about data and permissions.

1. Consent the App asks for

The App does not ask for any consent, because it does not process personal data that would require it: there is no advertising, no analytics, no tracking and no cloud service. For this reason the App has no Google consent dialog (UMP) and does not show Apple's App Tracking Transparency prompt.

2. Permissions

The App does not request any runtime permission (no notifications, location, camera, microphone, photos or contacts). Choosing your own music file uses the system file picker: the App only gets the single file you pick.

3. Changing your choices

You control all data in the App directly: turn background music on or off in the routine player, change the app language and delete all data in Settings ("Start over"), or uninstall the App. If a future version introduces ads, analytics or another feature that needs consent, it will ask for it first, and this page will describe how to change your choice.
